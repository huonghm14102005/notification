# Cẩm Nang Kiến Thức Dự Án

Tài liệu kiến thức chi tiết đã được biên soạn đầy đủ tại:
👉 **[knowledge.md](file:///d:/Workspace/StartUp/notification-server/knowledge.md)**

Vui lòng mở file [knowledge.md](file:///d:/Workspace/StartUp/notification-server/knowledge.md) để tra cứu:
1. Kiến trúc hệ thống Asynchronous Event-Driven & lý do dùng mã phản hồi `202 Accepted`.
2. Phân loại 3 vai trò thiết bị (`source`, `recipient`, `both`) & nguyên tắc Least Privilege.
3. Bản chất Mobile Push Endpoint (FCM/APNs) và Webhook Callback (HMAC-SHA256).
4. Kinh nghiệm thực chiến Render Free Tier chặn cổng SMTP TCP và giải pháp Resend HTTPS Port 443 Bypass.
5. Giới hạn của tài khoản Resend Free Tier (`onboarding@resend.dev`).
6. Quy trình 4 bước xác định Hardware Device ID trên ứng dụng Mobile thực tế.
7. Cẩm nang kiểm thử thực chiến không cần code mobile: Test Email, Test API Key bằng cURL, Test Webhook qua `webhook.site`, Test Push Token Mock.
8. Bảng tra cứu mã lỗi và cách khắc phục nhanh.
